# Facebook Poster Finder

Herramienta web para extraer la imagen de portada (poster) de videos públicos de Facebook.

## Características

- Extrae la imagen poster de videos de Facebook
- Soporta múltiples formatos de URL
- Interfaz simple y fácil de usar
- Opción para descargar la imagen

## Cómo usar

1. Ingresa la URL de un video público de Facebook
2. Haz clic en "Buscar"
3. Descarga la imagen usando el botón correspondiente

## Ejemplos de URLs válidas

- https://www.facebook.com/watch/?v=790096329309244
- https://fb.watch/abc123def/
- https://www.facebook.com/user/videos/1234567890/

## Limitaciones

- Solo funciona con videos públicos
- Facebook puede cambiar su estructura y afectar el funcionamiento
- Algunos videos pueden mostrar imágenes genéricas

## Instalación

1. Clona este repositorio
2. Abre `index.html` en tu navegador
