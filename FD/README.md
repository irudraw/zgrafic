# Facebook Poster Finder

Aplicación web para obtener la imagen poster de videos de Facebook.

## Cómo usar

1. Ingresa la URL de un video público de Facebook
2. Haz clic en "Buscar"
3. Descarga la imagen poster cuando aparezca

## Limitaciones

- Solo funciona con videos públicos
- Facebook puede cambiar su estructura y romper esta herramienta
- Algunos videos pueden mostrar imágenes genéricas

## Instalación local

1. Clona este repositorio
2. Abre `index.html` en tu navegador
